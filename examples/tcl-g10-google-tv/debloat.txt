# TCL 55" 4K Google TV, 2023 model year, US (device G10, product G10_4K_US_NF, Realtek RTD2875P)
# Android 12 (Google TV, basic mode), firmware STT2.230203.001, software V8-R75PT01-LF1V499
# Likely a good starting point for other 2023+ TCL Google TV sets on the Realtek G10 platform.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g10-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g10-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh, the default is wrong here).
# Live TV app: com.tcl.tv (keep it, it also owns HDMI/antenna playback). Keep com.tcl.tvinput,
# com.tcl.dashboard, com.tcl.suspension, com.tcl.autopair and com.tcl.systemserver too.
# Already disabled at the factory on the first unit: com.tcl.logkit, tv.samba.ssm.ui (Samba TV ACR),
# com.tcl.ttvs. A second unit on the same firmware (model "Smart TV Pro", Wi-Fi only) shipped all three
# ENABLED, so they are listed below; on a set where they are already off the lines do nothing.
# com.tcl.tv.plus and com.tcl.smartlink.core were not installed on the second unit at all.
#
# Second unit: the whole list below, minus the Optional block, applied 2026-10-19 in four batches;
# Wi-Fi, Home and all inputs (tuner + 3 HDMI) checked after each batch and again after a reboot.
#
# Known quirks on this firmware:
# - The red "TV" tile disappears from the Google TV Home row after this list (probably
#   com.tcl.partnercustomizer). TV stays in the Apps row and behind the Inputs tile.
# - Disabling dreamx leaves screensaver_components pointing at it. Switch to the AOSP fallback with
#   tools/tv.py 'settings put secure screensaver_components com.android.dreams.basic/.Colors'
#   That fallback is plain colour gradients with no options. To get Ambient mode back, re-enable dreamx
#   AND point the setting back at it; enabling the package alone leaves the gradients:
#   tools/tv.py 'pm enable --user 0 com.google.android.apps.tv.dreamx; settings put secure screensaver_components com.google.android.apps.tv.dreamx/.service.Backdrop'
# - screencap writes an empty file while Live TV/HDMI is on screen. Press Home first.
# - The Google TV promo banner is drawn by launcherx itself, so only launcher/ removes it.
#
# DO NOT DISABLE com.google.android.tungsten.setupwraith on this firmware (second unit, 2026-10-19).
# Within half a second of `pm disable-user` killing it, wificond reset the Wi-Fi regulatory domain and
# the TV dropped off Wi-Fi and forgot the saved network; the password had to be typed in again on the
# TV. No reboot was involved. Re-enabling it did not drop Wi-Fi. The catch: setupwraith's
# .RecoveryActivity claims HOME at priority 1, so with launcherx disabled Home lands on it, and with
# launcherx enabled (priority 2) `set-home-activity` saves the preference but Android never consults
# it. The launcher half is therefore unverified on the G10 so far. If you try it, plug in Ethernet
# first so ADB survives a Wi-Fi drop, and reboot twice with launcherx still enabled to check that Wi-Fi
# and the setupwraith disable both survive before disabling launcherx.
